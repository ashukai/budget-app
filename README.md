# Budget + Savings

A small personal web app for salary day: what to move between accounts, the usual monthly budget, and how savings grow.

This repository holds only the app. It contains no budget data. Each person's data stays on their own devices and in a private repository they choose in the app's Sync screen, using a key that never leaves their device.

Works offline once opened. Add it to the iPhone Home Screen from Safari (Share → Add to Home Screen).
